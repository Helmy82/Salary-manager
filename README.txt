تحديث قائمة المشتريات والرسوم البيانية
1) في مستودع GitHub افتح Upload files وارفع index.html وmanifest.webmanifest وsw.js من هذا المجلد إلى جذر المستودع مع استبدال الملفات القديمة.
2) ارفع wishlist_setup.sql أيضاً إلى جذر المستودع (أو افتحه وانسخ محتواه).
3) افتح Supabase > SQL Editor > New query وانسخ محتوى wishlist_setup.sql ثم Run مرة واحدة.
4) انتظر اكتمال GitHub Pages ثم افتح التطبيق على الجهازين. حدّث الصفحة أو أغلق التطبيق وافتحه مرة أخرى لتحديث التخزين المؤقت.
قائمة المشتريات محفوظة في جدول منفصل ولا تدخل في إجمالي الإيرادات أو المصروفات أو الرصيد. الرسوم البيانية تفصل الإيرادات والمصروفات حسب التصنيف ويمكن عرض الشهر الحالي أو كل الفترات.
