تحديث تطبيق إدارة مرتبي - ميزانية وتقارير ونسخ احتياطي

محتويات التحديث:
- قائمة المشتريات والملاحظات (مستقلة عن الحسابات المالية).
- رسوم بيانية للإيرادات والمصروفات حسب التصنيف.
- حدود ميزانية شهرية لكل تصنيف مع متابعة المتبقي والتنبيه عند تجاوز الحد.
- تقرير شهري ومقارنة بالشهر السابق.
- تنزيل نسخة احتياطية كاملة بصيغة JSON، وتصدير سجل الحركات بصيغة CSV المتوافقة مع Excel.

طريقة التحديث:
1) احتفظ بنسخة من ملفات المستودع الحالية قبل الاستبدال.
2) افتح مستودع GitHub: https://github.com/Helmy82/Salary-manager
3) ارفع الملفات index.html وmanifest.webmanifest وsw.js إلى جذر المستودع مع استبدال النسخ القديمة.
4) افتح Supabase > SQL Editor > New query.
5) انسخ محتوى wishlist_setup.sql بالكامل ثم اضغط Run مرة واحدة. السكربت ينشئ/يحدّث جدولي قائمة المشتريات والميزانيات فقط، ولا يحذف أو يعدّل جدول salary_transactions.
6) بعد نجاح SQL، افتح التطبيق على الجهازين وسجّل الدخول بنفس الحساب. حدّث الصفحة أو أغلق التطبيق وافتحه مجدداً.

مهم:
- لا تحذف جدول salary_transactions ولا تنفّذ أي أوامر لحذف بياناته.
- قائمة المشتريات وحدود الميزانية لا تخصم أموالاً من الرصيد.
- النسخة الاحتياطية JSON تشمل الحركات وقائمة المشتريات والميزانيات. CSV يشمل سجل الحركات لفتحه في Excel.
- لم يتم اختبار المزامنة على جهازك بعد هذا التحديث؛ اختبر إضافة حد ميزانية وعنصر مشتريات على جهاز، ثم تحقق من ظهورهما على الجهاز الآخر.
